# Admin Dashboard

## Overview

A responsive Admin Dashboard built with HTML and CSS, featuring a sidebar for navigation, a top bar with search and user profile, and a main content area with project cards, announcements, and trending items. It uses CSS Grid and Flexbox for layout and the Roboto font from Google Fonts.

## Features

- **Sidebar Navigation**: Menu with Home, Profile, Messages, History, Tasks, Communities, Settings, Support, and Privacy.
- **Top Bar**: Search bar, notification bell, user profile, and action buttons (New, Upload, Share).
- **Projects Section**: 2-column grid of project cards with titles, descriptions, and action icons.
- **Announcements & Trending**: Right column with recent updates and trending users/projects.
- **Responsive Design**: Adapts to various screen sizes (mobile optimization planned).
